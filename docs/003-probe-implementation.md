# 探针业务实施记录

日期：2026-10-13。本文记录组织探针从占位页面到完整前端业务的扩展，更新 002 文档中“探针尚未实现”的历史范围说明。

## 实施范围

- `/probes`：组织探针列表、名称/ID/区域/回调地址搜索、状态与供应商筛选、URL 保留筛选与分页。
- `/probes/overview`：节点总数、在线/离线/停用数、去重绑定监控数、检查结果数、供应商分布、最近添加及筛选跳转。
- 注册：后端一次性安装命令和手动注册两种模式；编辑名称、供应商、区域、回调地址、启用状态。
- 节点操作：启停、创建连通校验挑战、确认后轮换密钥、确认后删除。
- 详情抽屉：节点信息、跨项目监控候选、增量绑定、确认解绑、检查结果与执行日志。
- 历史记录：服务端分页、完整目标筛选；执行日志支持状态与触发方式筛选、错误及请求/响应元数据。
- 中英文、深浅主题及桌面/平板/手机布局。

## 实际契约

以本地后端 `D:/WorkSpace/beacon/src/modules/probes` 的控制器、DTO、实体和服务为准；前端不新增后端路由。

所有组织管理接口以 `/api/organizations/:orgId/probes` 为基础：

| 方法                 | 路径                       | 用途                                            |
| -------------------- | -------------------------- | ----------------------------------------------- |
| GET / POST           | `/`                        | 列表 / 手动注册                                 |
| GET / PATCH / DELETE | `/:id`                     | 详情 / 编辑或启停 / 删除                        |
| POST                 | `/enroll-token`            | 生成安装凭证及命令，不提前创建节点              |
| POST                 | `/:id/rotate-secret`       | 轮换密钥，旧密钥宽限期为 24 小时                |
| POST                 | `/:id/validate`            | 创建挑战，返回 `validationId/expiresAt/status`  |
| POST                 | `/:id/monitors`            | `{ monitorIds }` 增量绑定，每次 1 至 100 个     |
| DELETE               | `/:id/monitors/:monitorId` | 解绑单个监控项                                  |
| GET                  | `/:id/results`             | `page/limit/target` 筛选检查结果                |
| GET                  | `/:id/executions`          | `page/limit/target/status/trigger` 筛选执行日志 |

历史接口先解开全局 `{ data, meta: { timestamp } }` 响应封装，再保留内部 `{ data, meta: { total, page, limit, totalPages } }` 分页结构。

监控候选沿用现有 `useOrganizationMonitors`，只在组织管理员打开绑定区域后获取组织项目及各项目监控。项目级最小探针候选接口仍用于项目业务，不能用于获取完整组织探针配置。

## 权限与凭证

- 页面和完整探针读取要求组织 `manageOrganization` 权限，项目 ADMIN 不获得组织探针管理权限。
- 每次写操作前强制重新确认组织权限；同一操作上下文的重复点击被串行保护。
- 切换组织、权限失效、退出登录或卸载页面后，旧响应不回填；列表、详情及历史读取使用请求代次与 AbortController。
- 创建/轮换凭证只在当前弹窗显示，不进入列表、持久化 store 或浏览器存储；读取及绑定响应也会剔除意外返回的 `secret`。
- 关闭凭证弹窗、切换团队或丢失权限即清空凭证。安装凭证过期后隐藏命令与复制操作。
- 连通校验只展示后端挑战状态，不将 `PENDING` 误报为校验成功。
- 探针页面不参与 keep-alive，避免缓存一次性凭证和组织配置。

## 验证与边界

回归入口：

```bash
pnpm test:unit
pnpm type-check
pnpm type-check:test
pnpm test:e2e
pnpm build
```

探针相关测试位于 `test/unit/probe-api.spec.ts`、`test/unit/probe-business.spec.ts` 和 `test/e2e/probes.spec.ts`。浏览器测试使用隔离 mock，覆盖业务请求契约、项目管理员越权、权限撤销、迟到轮换响应、一次性密钥、过期安装凭证、日志分页及 1440/768/390px 深浅主题截图。

本地验收：58 项单元测试、52 项浏览器回归用例（含 17 项探针用例）、应用与测试类型检查、生产构建，以及新增代码 ESLint/Prettier 检查均通过。响应式截图已人工检查，修正了手机端分页总数裁切；注册字段使用原生 label 提供可访问名称。

接口已与后端源码核对，但上述自动测试不是实际探针代理、数据库或生产环境的端到端联调。设备码审批页面与代理自身的安装、心跳、上报、吊销属于后端/代理流程，不在本轮组织探针管理页面范围内。真实安装和回调校验仍需连接后端及代理验证。
